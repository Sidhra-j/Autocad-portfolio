## AutoCAD Portfolio:

Technical drawing created in AutoCAD Mechanical, starting with a detailed Batmobile blueprint recreation (2017).

A detailed top-view recreation of a published Batmobile reference blueprint, completed as part of an AutoCAD (Mechanical) course and checked by the course instructor

Starting with the units & limits, the scale is set to the desired unit.
The different layers based on different parts are assigned. Once the layers have been created, each layer is selected based on the part that is to be drawn. This provides for clear distinction between different parts of the automobile.
Starting the design with the front headlamps, the Batmobile was drawn using various drawing tools such as arc, line, circle, rectangle, and various other functions such as trimming, extending, chamfering, hatching, fillet, etc.
One half of the automobile was made and the ‘mirror’ command was used to complete the model. 
Using dimensioning, the various parts were assigned their particular dimensions. Different parts were labelled using text insertion method.
The table of specifics is included as per drawing standards (BOM). With the help of layers, the different parts can be viewed with ease in the final printout of the drawing.

## 📐 Demonstrations:
Efficient techniques, precision-scaling, layer management, dimensioning, standards, hatching & mechanical detailing.
